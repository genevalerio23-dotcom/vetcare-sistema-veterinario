# VetCare - Sistema de Gestion Veterinaria 
 
Proyecto Integrador de la asignatura Arquitectura de Software. 
 
## Descripcion 
VetCare es un sistema para la gestion de una clinica veterinaria. 
Permite administrar clientes, mascotas, citas, consultas, tratamientos, medicamentos y pagos. 
 
## Arquitectura 
El proyecto utiliza una arquitectura en capas: 
 
- Presentacion 
- Aplicacion 
- Dominio 
- Infraestructura / Persistencia 
 
## Estado del proyecto 
Proyecto en etapa inicial de analisis y diseno arquitectonico.
